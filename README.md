# DrGeo — Rehmat Ali

A Next.js App Router website for a GEO and AEO specialist.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Stack

- Next.js App Router
- JavaScript
- React
- Tailwind CSS
- Lucide React

This is the initial project foundation. Advanced SEO/GEO implementation is intentionally reserved for a later phase.
